# 🚨 Incident Response
## Detection, Containment, and Recovery Framework

---

## 🚩 Executive Summary
This folder demonstrates the structured approach to handling security breaches and operational disruptions. It highlights the ability to translate high-pressure operational experience into technical **Incident Response Playbooks** that minimize business impact and ensure regulatory compliance.

---

## 🛠️ Incident Life Cycle (NIST SP 800-61)
Documentation in this section follows the four-phase approach to incident handling:
1.  **Preparation:** Hardening systems and training teams (e.g., Security Awareness).
2.  **Detection & Analysis:** Identifying anomalies via logs and user reports.
3.  **Containment, Eradication & Recovery:** Isolating affected systems and restoring service.
4.  **Post-Incident Activity:** Documenting "Lessons Learned" to prevent recurrence.

## 📜 Regulatory Reporting Alignment
*   **RA 10173 (DPA 2012):** Procedures for the mandatory **72-hour notification** requirement to the National Privacy Commission (NPC) in the event of a data breach.
*   **BSP Circular 808:** Operational resilience standards for financial institutions during system outages or cyber-attacks.
